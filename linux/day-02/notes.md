# День 2 - Файлы, поиск и права доступа

## Что изучил

- find - поиск файлов и директорий
- grep - поиск текста внутри файлов
- ls -l - просмотр прав доступа владельца
- chmod - изменение прав доступа
- stat - информация о файле

## Права доступа Linux

- r - чтение
- w - запись
- x - выполнение

Пример:

-rw-rw-r--

- владелец: rw-
- группа: rw- 
- остальные: r--

## Мини-расследование

Проанализировал suspicious.log

Обнаружил:

- несколько не удачных попыток вода
- попытка входа для пользователей admin и root
- IP-адрес 192.168.1.50

Предварительный вывод:

В логе присутствуют признаки подозрительной активности, похожей на перебор паролй.
При этом по одному логу нельзя точно утверждать, что IP 192.168.1.50 является источником всех неудачных попыток входа.

## Главный вывод

При анализе Linux нужно обращать внимание не только на содержимое файлов, но и на:

- владельца
- права доступа
- время изменения
- расположение файла
- подозрительное содержимое

Эти навыки пригодятся при дальнейшем аналзе инцидентов и логов в SOC
