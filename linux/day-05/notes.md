# День 5 - Linux сети

## Команды
-`ip a` — сетевые интерфейсы и IP-адреса
-`ip route` — таблица маршрутизации
-`ip route get <IP>` — маршрут до адреса
-`ip rule` — правила маршрутизации
-`ping -c 4 <IP>` — проверка доступности узла
-`resolvectl status` — настройки DNS
-`getent ahostsv4 <domain>` — IPv4-адреса из системного разрешения имён
-`dig <domain>` — DNS-запрос
-`curl -I <URL>` — запрос HTTP-заголовков

## Что выяснил
-Wi-Fi
-Локальный IP
-Шлюз
-DNS через VPN
-`curl -I https://example.com` вернул HTTP 200
