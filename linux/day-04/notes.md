# День 4 - Пользователи и привелегии Linux

## Что изучил

-whoami - текущий пользователь
-id - UID, GID и группы пользователей
-grep "/home" /etc/passwd - поиск пользователей с домашними директориями
-sudo -l - просмотр разрешенных команд через sudo
-getent group sudo - просмотр участников группы sudo

# Главный вывод

-При анализе безопасности Linux важно проверить:

-существующие учетные записи
-группы пользователей
-административные привилегии
-разрешения на использование sudo

Учетная запись с административными привилегиями требует особого внимания при расследовании инцидентов
